# 20-minute weekly review

`.github/workflows/weekly-review.yml` opens an issue every Monday at 9:00 ET from `.github/WEEKLY_REVIEW_ISSUE.md`. Work it top to bottom, then close it. Run it any time from Actions > Weekly review > Run workflow.

| Minutes | Focus |
|---|---|
| 5 | [GitHub Changelog](https://github.blog/changelog): Apps, REST, webhooks, Actions. Feature preview changes |
| 5 | Usage and spend: Actions minutes, rate-limit headroom, failed deliveries |
| 5 | User friction: support inbox, pilot feedback, recoverable-state replies |
| 5 | Pick the next smallest release and link its issue |

Monthly: reverify any credit or program terms in `docs/CREDIT_PROGRAMS.md`.
