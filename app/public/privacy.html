Privacy Policy

Effective October 23, 2026

This policy covers the GRYT Skills GitHub App ("the App"), operated by GRYT ("we"). Contact: nick@gryt.club.

What the App can access

Only the repositories you choose when you install it, with these permissions: read repository metadata, read and write repository contents, and read and write issues. You can change the repositories or uninstall at any time from your GitHub settings.

What the App does with that access

  • Reads SKILL.md and workflows/*.md files when you run a /gryt command.
  • Creates labels, a milestone and issues in the repository where you ran the command.
  • Writes a check-in file under gryt/checkins/ when you close a GRYT plan issue.

What we store

We do not keep a database of your repository contents, issues or comments. Files are read during a request and are not retained after it completes. Our hosting provider keeps short-lived request logs, which include event type, action, account login and repository name, for debugging and abuse prevention. We do not sell data, run ads or use your content to train models.

GitHub Marketplace

If you install through GitHub Marketplace, GitHub sends us plan events (purchase, change, cancellation) with your account login and plan name. GRYT Skills is free, so we never receive payment details.

Deleting your data

Uninstall the App to revoke access immediately. Everything the App created lives in your own repository, so you control it. Email us to request deletion of any logs tied to your account.

Changes

We'll update the date above and note material changes on this page.
