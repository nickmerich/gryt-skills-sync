Support

Email nick@gryt.club. Include the repository and the command you ran. We aim to reply within two business days.

Common fixes

  • "I can't see any SKILL.md files." Add the repository that holds your library to the installation under GitHub Settings, Applications, GRYT Skills, Configure.
  • "I couldn't find that skill." The name is the folder that holds SKILL.md, or the file name under workflows/. Run /gryt list.
  • Running a plan twice. Safe. GRYT keeps existing issues and refreshes the tracking issue.
  • No check-in after closing. Only the issue titled GRYT plan: ... with the gryt-plan label triggers it.
  • "GitHub is rate limiting me." Wait until the time in the reply and run the same command again. Nothing duplicates.
  • "I can't read that skill anymore." Its repository was removed from the installation. Add it back under Configure.
  • "I won't copy it here." The skill is in a private repo and you ran the command in a public one. Use a private repo.
  • "I can't turn that into a plan." The file needs at least one ## section with steps, closed front matter, and under 200 KB.
  • Check-in arrived as a comment. The app couldn't write files in this repo (read-only install or protected branch), so it saved the check-in on the tracking issue instead.
