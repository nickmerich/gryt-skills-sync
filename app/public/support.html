Email nick@gryt.club. Include the repository and the command you ran. We aim to reply within two business days.

Common fixes

  • "I can't see any SKILL.md files." Add the repository that holds your library to the installation under GitHub Settings, Applications, GRYT Skills, Configure.
  • "I couldn't find that skill." The name is the folder that holds SKILL.md, or the file name under workflows/. Run /gryt list.
  • Running a plan twice. Safe. GRYT keeps existing issues and refreshes the tracking issue.
  • No check-in after closing. Only the issue titled GRYT plan: ... with the gryt-plan label triggers it.
