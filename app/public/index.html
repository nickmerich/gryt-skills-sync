Turn your playbooks into plans you actually work.

GRYT Skills reads the skill guides and workflow templates in a repository you choose, turns one into a GitHub milestone with an issue for every step, and saves a check-in back to your repo when you finish.

How it works

1. Install on the repos you pick. Only the repositories you select. Your library stays private.
2. Comment /gryt list on any issue to see the skills GRYT can read (any SKILL.md or workflows/*.md).
3. Comment /gryt plan newcomer-welcome. GRYT creates a 4-week milestone, one issue per section with every list item as a checkbox, and a tracking issue grouped by week. Run it again and nothing duplicates.
4. Close the plan. GRYT writes gryt/checkins/DATE-plan.md to your repo: what got done, what carries over and the notes you left on each task.

Commands

/gryt list                    # skills and workflows GRYT can read
/gryt plan <skill> [weeks]     # build the plan (default 4 weeks)
/gryt help

Or open an issue titled GRYT plan: <skill>.

Who it's for

Runners, former athletes, parents, coaches and creative operators who keep their routines in a repo and want them to turn into weekly work, not a doc nobody opens.
